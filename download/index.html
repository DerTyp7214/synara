Download Synara

The apps are free. They connect to a Synara server you run yourself, so start there if you don't have one yet.

Release channel

Release builds. Android has one. Desktop and the server have none yet, so they use the current dev builds.

Desktop

Linux and Windows (x64), macOS (Apple Silicon). Fullscreen visualizer and lyrics, Discord rich presence, and MPRIS plus a D-Bus API on Linux.
