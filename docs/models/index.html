Data Models

Album

Full name: dev.dertyp.data.Album

Contains metadata about a collection of songs released together.

Field Type Description
id PlatformUUID The album unique identifier.
name String The name of the album.
artists List<ArtistCredit> Collection of artists credited for this album.
songCount Int Total number of songs in the album.
releaseDate PlatformLocalDate? The date the album was released.
totalDuration Long Sum of all track durations in milliseconds.
totalSize Long Total file size of all tracks in bytes.
coverId PlatformUUID? The album cover image unique identifier.
blurHash String? The blur hash of the album cover image.
genres List<Genre> Collection of genres associated with this album.
originalId String? The original ID of the album on external sources.
barcode String? The barcode or UPC of the album.
musicBrainzId PlatformUUID? The MusicBrainz Release unique identifier.
animatedCoverId PlatformUUID? The animated cover unique identifier.
animatedCoverImageId PlatformUUID? Identifier of the still Image from the animated cover's first frame.
animatedCoverBlurHash String? BlurHash of the animated cover's first frame.
tags List<TitleTag> Edition markers split off the name, e.g. Deluxe Edition, 10th Anniversary or 2011 Remaster, in order of extraction. The name never contains them.
versions List<Album> Other editions of the same album folded under this entry, such as deluxe, anniversary, remastered, explicit or clean variants. Each keeps its own identifiers and cover. Their own versions lists are always empty. Only filled by calls that return albums grouped into editions.
versionGroupId PlatformUUID? Identifies the group of editions this album belongs to. Albums with the same value are editions of each other. It stays the same for as long as the group exists.

AlbumExtendedMetadata

Extended metadata for an album.

Field Type Description
providers List<ProviderEntry> List of all external providers and IDs matching this album.

AnimatedImage

Metadata for a stored animated cover (a short looping video, e.g. motion album art).

Field Type Description
id PlatformUUID The animated image unique identifier.
path String Internal server path to the animated image file.
contentHash String Unique hash of the animated image content.
origin String The source or platform where the animated image originated.
format String? Container/format of the animated image (e.g. mp4, webm).
imageId PlatformUUID? Identifier of the still Image extracted from the first frame.
blurHash String? BlurHash of the first frame, surfaced for placeholders.

ApiKeyInfo

Metadata about an API key. Never contains the secret itself.

Field Type Description
id PlatformUUID The API key unique identifier.
label String Human-readable label describing where the key is used.
createdAt Long Unix timestamp (ms) when the key was created.
lastUsed Long? Unix timestamp (ms) of the last successful authentication with this key, if any.
expiresAt Long? Unix timestamp (ms) at which the key expires, if ever.
isRevoked Boolean Whether the key has been revoked.
scopes List<String> Identifiers of the scopes granted to this key.

ApiKeyScopeInfo

Describes an API key scope that can be granted to keys.

Field Type Description
id String The unique scope identifier.
name String Human-readable scope name.
description String Description of what the scope grants access to.
source String Origin of the scope: "server" for built-in scopes, otherwise the id of the plugin that registered it.

Artist

Full name: dev.dertyp.data.Artist

Contains metadata about a music artist or group.

Field Type Description
id PlatformUUID The artist unique identifier.
name String The name of the artist.
isGroup Boolean Whether the artist record represents a group of individuals.
artists List<Artist> Collection of sub-artists if this is a group.
about String A short biography or description of the artist.
genres List<Genre> Collection of genres associated with this artist.
imageId PlatformUUID? The artist image unique identifier.
blurHash String? The blur hash of the artist image.
musicBrainzId PlatformUUID? The MusicBrainz Artist unique identifier.
isFollowed Boolean Whether the current user is following this artist.
creditedName String? The name this artist was credited as in the current song/album context, if different from the canonical name.
joinPhrase String? The phrase that follows this artist in the credit of the current song/album context, such as " & " or " feat. ". Null when the credit source has none.

ArtistAlias

Represents an alternative name for an artist.

Field Type Description
artistId PlatformUUID The artist unique identifier.
name String The alternative name.

ArtistCredit

An artist as credited on a song or album. Carries the same fields as a full artist without the biography.

Field Type Description
id PlatformUUID The artist unique identifier.
name String The name of the artist.
isGroup Boolean Whether the artist record represents a group of individuals.
artists List<ArtistCredit> Collection of sub-artists if this is a group.
genres List<Genre> Collection of genres associated with this artist.
imageId PlatformUUID? The artist image unique identifier.
blurHash String? The blur hash of the artist image.
musicBrainzId PlatformUUID? The MusicBrainz Artist unique identifier.
isFollowed Boolean Whether the current user is following this artist.
creditedName String? The name this artist was credited as in the current song/album context, if different from the canonical name.
joinPhrase String? The phrase that follows this artist in the credit of the current song/album context, such as " & " or " feat. ". Null when the credit source has none.

ArtistPlaylistSortStrategy

Strategy for sorting songs when creating a playlist from artists.

Value Description
MB_RELEASE_DATE Sort by MusicBrainz release date (newest first).
MB_RELEASE_DATE_ASC Sort by MusicBrainz release date (oldest first).
SHUFFLED Randomly shuffle the songs.
ALBUM_ORDER Group by artist and album, following track order.
BY_GENRE Group by genre.

ArtistSplitAlias

Represents a split mapping for a combined artist name.

Field Type Description
artistId PlatformUUID The artist unique identifier.
name String The name to be split.

ArtistType

The category of a MusicBrainz artist.

Value Description

GROUP
ORCHESTRA

CHARACTER

AudioBand

Frequency band of a song's level tracks.

Value Description
SUB Sub bass, 20-60 Hz.
KICK Kick and bass fundamentals, 60-130 Hz.
LOW_MID Low mids, 130-400 Hz.
MID Mids, 400-2000 Hz.
HIGH Highs, 2000-8000 Hz.

AudioFormat

Supported audio formats for transcoding.

Value Description
OPUS Opus audio codec in Ogg container.
AAC Advanced Audio Coding in MP4 container.

AudioInfo

Physical properties of one audio file belonging to a song.

Field Type Description
codec String Audio codec of the file, e.g. flac, wav, eac3.
sampleRate Int Audio sample rate in Hz.
bitsPerSample Int Number of bits per audio sample. 0 for lossy codecs.
bitRate Long Audio bit rate in kilobits per second.
fileSize Long Size of the audio file in bytes.
channels Int Number of audio channels, e.g. 2 for stereo or 6 for 5.1.

AudioScale

The musical scale of a track.

Value Description
Major
Minor
MajMin
Unknown

AuthenticationRequest

Request payload for user authentication.

Field Type Description

Response payload containing JWT tokens after successful authentication.

Field Type Description

BackupImage

Contains raw binary data for a cover image in a backup.

Field Type Description
image Image Metadata for the image.
data ByteArray The raw binary data of the image.

Change

A notification that a piece of the user's state changed. It carries no data, so the client reads the new state with the getter the ChangeTopic names.

Field Type Description
topic ChangeTopic What changed. Topics a client does not know are decoded as UNKNOWN.

ChangeTopic

The kind of state a change notification is about. Each topic names the getter a client calls again to read the new state.

Value Description
UNKNOWN A topic this client does not know yet. Clients ignore it.
ONLINE_DEVICES The connected devices of the user changed. Read them again with IClientRequestService.getOnlineDevices.
HOME_CARDS The pinned home cards or their layout changed. Read them again with IUiService.getHomeCards.
LISTENS The listen history or the song playing right now changed. Read it again with IScrobbleService.recentListens, IScrobbleService.recentArtists or IScrobbleService.recentAlbums.
LISTENBRAINZ_STATUS The ListenBrainz link or its sync status changed. Read it again with IListenBrainzService.getStatus.

ClientCapability

A cross-device feature a client offers for as long as it keeps its request subscription open.

Value Description
QUEUE_SYNC The client keeps the shared play queue in sync and can be asked to upload its own queue.
REMOTE_CONTROL The client accepts transport commands from other devices of the user and reports what it is playing.
REMOTE_VOLUME The client can change its playback volume on request, which is not possible on every platform.

ClientDescription

How a client describes itself when it connects to the request channel. The description is kept only while the connection is open, so a client resubscribes to change it.

Field Type Description
deviceName String Human readable name the device is listed under on the other devices of the user.
platform String Free-form platform label of the device, for example Android, iOS or Desktop.
deviceId String? The settings synchronization device identifier of the client, when it has one, so other devices can correlate the connection with stored settings.
capabilities Set<ClientCapability> The cross-device features this client offers while the connection is open.

ClientDevice

A device of the user that stores settings on the server. Devices are identified by a stable identifier the client generates and persists itself.

Field Type Description
deviceId String The stable identifier the client chose for itself.
name String Human readable name the device reported for itself.
platform String Platform the device reported for itself, for example the operating system it runs on.
createdAt Long Unix timestamp in milliseconds at which the device was first seen.
lastSeenAt Long Unix timestamp in milliseconds of the last time the device read or wrote its settings.
settingsVersion Long The current version of the device scope of this device, or 0 if it never stored a device setting.

ClientRequest

A task the server asks a specific client session to perform. Clients observe these and answer by calling the matching RPC methods.

Field Type Description
id PlatformUUID Identifier of this request, reported back when the client completes it.
requestedAt Long Unix timestamp in milliseconds at which the request was issued.

ControlPlayback

Another device of the same user asks this client to change its playback. The client applies the command, publishes its new status through the remote control service and answers with complete, reporting the request as rejected when it does not apply the command. This request is only sent to sessions that connected with the remote control capability.

TimecodeTagAction

What the client that plays the song does when playback reaches a timecode tag. The playing client executes the action itself, a client that only controls another device does nothing. Chapter actions need a tag with an end position, marker actions a tag without one, and a note always uses NONE.

Value Description
NONE The tag is passive and does not change playback.
PLAY_ONLY Chapters only. Playback covers only the PLAY_ONLY chapters of the song and moves on to the next track after the last one.
SKIP Chapters only. Playback jumps over the chapter.
SKIP_TO Markers only. The song starts at the marker.
PLAY_UNTIL Markers only. Playback moves on to the next track when it reaches the marker.
